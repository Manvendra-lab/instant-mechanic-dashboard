# Instant Mechanic - Live Operations Dashboard

## Project Overview
A production-ready Live Vehicle Service Operations Dashboard built for the Instant Mechanic operations team. This system monitors bookings in real-time, allowing operators to search, filter by service category, and track status changes without page reloads.

## Tech Stack
* **Frontend:** Next.js, React, TypeScript, Tailwind CSS, shadcn/ui
* **Backend:** Python, FastAPI, WebSockets
* **Database:** MongoDB Atlas
* **Deployment:** Vercel (Frontend), Render (Backend)

Note on Deployment Pivot: The original assignment suggested AWS EC2 for backend hosting. Due to AWS account/billing restrictions, I adapted the architecture and deployed the FastAPI backend to Render. This successfully maintains a live, publicly accessible API with full WebSocket support for the real-time dashboard requirements.

## Architecture
Frontend (Next.js/React) 
  ↓ REST for initial data load / WebSockets for live updates
API (FastAPI) 
  ↓ Asynchronous queries (Motor)
Backend 
  ↓
Database (MongoDB Atlas cluster)

## Local Setup
1. Clone the repository: `git clone <repo-link>`
2. **Backend:** 
   * `cd backend`
   * `python -m venv venv`
   * `source venv/bin/activate`
   * `pip install -r requirements.txt`
   * Add MongoDB connection string to `main.py`
   * Run: `uvicorn main:app --reload`
3. **Frontend:**
   * `cd frontend`
   * `npm install`
   * Run: `npm run dev`

## API Documentation
Interactive Swagger documentation is automatically generated by FastAPI. 
Access it live at: `http://<YOUR_EC2_IP>:8000/docs`
* `GET /api/bookings` - Fetches paginated bookings.
* `PUT /api/bookings/{id}/status` - Updates status and broadcasts WebSocket event.
